## Before opening a request

Include the following when relevant:

- **Product or project name**
- **Version or build number**
- **Operating system / device / environment**
- **Reproduction steps**
- **Expected and actual behavior**
- **Non-sensitive logs or screenshots**

> [!IMPORTANT]
> You can request support here even when the active development repository is private. Access to the project repository is not required.

> [!WARNING]
> Do **not** post passwords, tokens, private keys, or sensitive vulnerability details in a public issue. Read [`SECURITY.en.md`](./SECURITY.en.md) before reporting a security issue.
