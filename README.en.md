## Start here

This repository is the shared public support entry point for **current and future SilverBell Choir projects**.

Working repositories may remain private during active development. You do not need access to those repositories to report a problem, request a feature, or ask for help.

## Support types

- **Bug Report** — something is broken or behaves unexpectedly
- **Feature Request** — suggest a new feature or improvement
- **General Support** — ask a question or request help

### [Open a support request →](https://github.com/Silverbell-Choir/silverbell-choir-support/issues/new/choose)

## Helpful information

Include when relevant:

- product or project name
- version or build number
- operating system, device, or environment
- reproduction steps
- expected and actual behavior
- non-sensitive logs or screenshots

## Security issues

**Do not post sensitive vulnerability details publicly.**

Read [`SECURITY.en.md`](./SECURITY.en.md) before opening a security-related report.

## About this repository

This repository is for public support intake. Product source code and active development may remain in private repositories while this support address stays stable as the organization grows.
