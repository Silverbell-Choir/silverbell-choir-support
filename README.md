## Start here

This repository is the shared public entry point for support across **current and future projects** maintained by SilverBell Choir.

Working repositories may remain private during active development. You do not need access to those repositories to report a problem, request a feature, or ask for help.

### Choose a support type

- **Bug Report** — something is broken or behaves unexpectedly
- **Feature Request** — suggest a new capability or improvement
- **General Support** — ask a question or request help

**[Open a support request →](https://github.com/Silverbell-Choir/silverbell-choir-support/issues/new/choose)**

## What to include

When relevant, include:

- product or project name
- version or build number
- operating system, device, or environment
- clear reproduction steps
- expected and actual behavior
- screenshots or non-sensitive logs

## Security issues

Do **not** post sensitive vulnerability details publicly.

Read **[`SECURITY.md`](./SECURITY.md)** before opening a security-related report.

## About this repository

This repository contains support intake only. Product source code and active development can remain in private repositories while this public support address stays stable as the organization grows.
