## 여기에서 시작하세요

이 저장소는 **SilverBell Choir에서 관리하는 현재 및 향후 프로젝트 전체의 공용 지원 창구**입니다.

실제 개발 저장소는 개발 단계에 따라 비공개일 수 있습니다. 해당 저장소에 접근할 수 없어도 이곳에서 문제를 제보하거나 기능을 요청하고 도움을 받을 수 있습니다.

### 지원 유형

- **버그 제보 / Bug Report** — 기능이 정상적으로 동작하지 않거나 예상과 다른 문제가 있을 때
- **기능 요청 / Feature Request** — 새로운 기능 또는 개선 아이디어를 제안할 때
- **일반 지원 / General Support** — 사용 문의나 도움이 필요할 때

**[지원 요청 만들기 →](https://github.com/Silverbell-Choir/silverbell-choir-support/issues/new/choose)**

## 작성하면 좋은 정보

상황에 맞게 아래 정보를 포함해 주세요.

- 제품 또는 프로젝트명
- 버전 또는 빌드 번호
- 운영체제, 장치, 실행 환경
- 재현 절차
- 기대한 동작과 실제 동작
- 민감하지 않은 로그 또는 스크린샷

## 보안 문제

**민감한 취약점 세부 내용을 공개 이슈에 작성하지 마세요.**

보안 관련 제보 전 [`SECURITY.md`](./SECURITY.md)를 먼저 확인해 주세요.

## 이 저장소의 역할

이 저장소는 공개 지원 접수 전용입니다. 제품 소스 코드와 실제 개발은 비공개 저장소에서 진행할 수 있으며, 조직에 새로운 프로젝트가 추가되어도 이 지원 주소는 공용 창구로 유지됩니다.

## English

This repository is the shared public support entry point for **current and future SilverBell Choir projects**.

Working repositories may remain private during active development. You do not need access to those repositories to report a problem, request a feature, or ask for help.

### Support types

- **Bug Report** — something is broken or behaves unexpectedly
- **Feature Request** — suggest a new feature or improvement
- **General Support** — ask a question or request help

**[Open a support request →](https://github.com/Silverbell-Choir/silverbell-choir-support/issues/new/choose)**

For security-related reports, do not post sensitive vulnerability details publicly. Read [`SECURITY.md`](./SECURITY.md) first.
