## 지원 요청 전에

아래 정보를 함께 적으면 확인이 빨라집니다.

- **제품 또는 프로젝트명**
- **버전 또는 빌드 번호**
- **운영체제 / 장치 / 실행 환경**
- **재현 절차**
- **기대한 동작과 실제 동작**
- **민감하지 않은 로그 또는 스크린샷**

> [!IMPORTANT]
> 실제 개발 저장소가 비공개여도 이곳에서 지원을 요청할 수 있습니다. 프로젝트 저장소 접근 권한은 필요하지 않습니다.

> [!WARNING]
> 비밀번호, 토큰, 개인키, 취약점 세부 내용 등 **민감한 보안 정보는 공개 이슈에 작성하지 마세요.** 보안 관련 제보는 [`SECURITY.md`](./SECURITY.md)를 먼저 확인해 주세요.
