# Support

This repository is the main public support channel for **SilverBell Choir**.

## Open an issue here for

- bug reports
- feature requests
- help requests
- documentation problems
- general questions about a SilverBell Choir project

## Include when possible

- product or project name
- version or build number
- operating system / device / environment
- a short, clear description of the issue or request
- screenshots or logs when relevant

## Security

If your report is security-related, read [`SECURITY.md`](./SECURITY.md) first.
