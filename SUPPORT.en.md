# Support

[한국어](./SUPPORT.md) · [English](./SUPPORT.en.md)

This repository is the **shared public support channel for SilverBell Choir**.

## Use this repository for

- bug reports
- feature requests
- usage questions
- documentation issues
- general questions about SilverBell Choir projects

## Include when possible

- product or project name
- version or build number
- operating system, device, or environment
- a short and clear description of the issue or request
- screenshots or non-sensitive logs when relevant

## Security issues

Read [`SECURITY.en.md`](./SECURITY.en.md) first for security-related reports.
