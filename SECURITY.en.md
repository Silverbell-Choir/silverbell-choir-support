# Security Policy

[한국어](./SECURITY.md) · [English](./SECURITY.en.md)

## Reporting security issues

**Do not post sensitive vulnerability details in a public issue.**

If you need to report a security-related issue:

1. Open a new issue in this repository.
2. Start the title with `[SECURITY] Private disclosure requested`.
3. Provide only minimal high-level information publicly.
4. Wait for private handoff instructions before sharing full technical details.

## Helpful information

- product or project name
- affected version or build
- short summary of the issue
- expected impact or risk
- whether the issue is confirmed or suspected

## Important

Public issues are visible to others. Keep sensitive details minimal until a private disclosure path has been arranged.
