# Security Policy

## Reporting security issues

Please **do not post sensitive vulnerability details publicly**.

If you need to report a security-related issue:

1. Open a new issue in this repository.
2. Start the title with: `[SECURITY] Private disclosure requested`
3. Provide only minimal high-level information.
4. Wait for follow-up before sharing full technical details.

## Helpful information to include

- product or project name
- affected version or build
- short summary of the issue
- impact or risk
- whether this is confirmed or suspected

## Important

Public issues are visible to others. Keep initial security reports limited until a private handoff can be arranged.
